Modular architecture — each layer does one job

  • Experience layer — this portal, a static site on GitHub Pages (Vercel later, if community and database elements call for it).
  • Media infrastructure — Cloudflare R2 object storage with CDN delivery for CTP's own audio assets.
  • Internet radio layer — laut.fm streams powering the Radio Wall and the player.
  • Artist ecosystem layer — Bandcamp releases and artist pages — the curated releases above.
  • Membership layer — Club CTP identity, access and tiers.

Separating the layers keeps the portal lean, secure and cheap to run — and free to scale when the community does.
